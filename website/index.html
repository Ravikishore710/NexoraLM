First-Principles Design

Compact GQA Architecture

Every layer built from fundamental PyTorch tensor operations with zero black-box dependencies.

Component Configuration Design Rationale
Attention Grouped-Query Attention (12 Q, 4 KV heads, Head Dim 64) 3:1 GQA sharing reduces KV-cache memory bandwidth by 66.7% while maintaining MHA expressive capacity.
Normalization RMSNorm (Pre-LN, ε = 1e-5) Replaces standard LayerNorm by removing mean-centering overhead; accelerates training throughput by ~7%.
Positional Embedding Rotary Positional Embeddings (RoPE, θ = 10,000) Relative positional encoding preserved across inner products with zero trainable parameters.
Feed-Forward SwiGLU (Hidden 768 → Intermediate 2048 → 768) Gated linear units with SiLU activation provide superior non-linear representational density.
Vocabulary & Tying Exact 32,768 Byte-level BPE Weight-tied LM head eliminates 25.17M redundant parameters and enforces symmetric vector space.
Linear Biases Disabled across all projections Modern standard (LLaMA/Mistral style) reducing parameter clutter and improving gradient flow.

Developer Setup

Run in 3 Commands

Clone, run the verified unit test suite, and launch the inference server locally.

BASH / POWERSHELL terminal 
# 1. Clone the repository
git clone https://github.com/Ravikishore710/NexoraLM.git
cd NexoraLM

# 2. Run all 22 automated unit tests
pytest tests/ -v

# 3. Start OpenAI-compatible FastAPI server with SSE token streaming
python scripts/serve.py --checkpoint checkpoints/nexoralm_aligned_300m.pt --port 8000

# 4. Connect interactive terminal chat client
python scripts/chat_cli.py
